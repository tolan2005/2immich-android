# 2immich

Приложение для Android: **выборочный обмен медиа в обе стороны между галереей телефона
и домашним сервером [immich](https://immich.app)** — с переносом метаданных и видимым
состоянием «что где лежит».

**[Скачать последнюю версию →](../../releases/latest)**

---

## Зачем

Официальное приложение immich делает автобэкап камеры целиком. `immich-go` на компьютере
умеет массовую загрузку. Ни то, ни другое не даёт **ручного выборочного обмена с телефона
в обе стороны** — выбрать десяток кадров и отправить на сервер, или забрать с сервера
конкретный альбом в галерею, не выгружая всё остальное.

## Что делает

Два равноправных направления, запускаемых **только по явному действию** — автоматического
бэкапа и автоудаления нет.

| Направление | Что происходит |
|---|---|
| **Телефон → immich** | Выбранные локальные фото и видео загружаются на сервер |
| **immich → телефон** | Выбранные серверные ассеты скачиваются в галерею |

Разделов два: **«На телефоне»** и **«На сервере»**. В каждом — сетка миниатюр, мультивыбор,
фильтры и собственный просмотрщик (зум, панорамирование, свайп).

**Что переносится вместе с файлом:** альбомы, избранное, оценка, описание, теги
и произвольные поля, а также **дата съёмки** — скачанное не сбивается в один день.

**Скачанное складывается отдельно от фото камеры:**

- фото — `Pictures/2immich/<альбом>/`
- видео — `Movies/2immich/<альбом>/`

**Очередь передач переживает перезапуск.** Перенос идёт в foreground-службе с уведомлением
и прогрессом; при потере сети очередь встаёт на паузу и продолжается, когда сервер снова
доступен, а неполный файл в галерее не остаётся мусором.

## Требования

- **Android 10 (API 29) и новее**
- Сервер **immich**, доступный **из домашней сети**. В интернет сервер публиковать не нужно
  и не предполагается: приложение обращается только к частным адресам (`192.168.x.x`,
  `10.x.x.x`, `172.16–31.x.x`, `127.x.x.x`, `.local`) по `http` или `https`.
- API-ключ immich и адрес сервера вводятся в настройках приложения. Ключ хранится
  в защищённом хранилище Android и с устройства не уходит.

## Установка

Приложение распространяется сайдлоадом, без Google Play.

1. Откройте **[последний релиз](../../releases/latest)** и скачайте файл
   `2immich-<версия>.apk`.
2. Разрешите установку из неизвестных источников для приложения, из которого открываете
   APK (браузер или файловый менеджер).
3. Установите APK.
4. При желании сверьте контрольную сумму — файл `SHA256SUMS` лежит в том же релизе:

   ```bash
   shasum -a 256 -c SHA256SUMS
   ```

Android при установке обновления проверяет подпись: она не меняется между версиями, поэтому
обновления ставятся поверх без удаления приложения.

## Обновления

Приложение умеет обновлять себя прямо из этого раздела Releases — вручную ходить за APK
не нужно.

Проверка запускается при старте (если включена настройка «Проверять обновления при запуске»,
по умолчанию включена) и вручную — пунктом «Проверить обновление» в настройках.

Если новая версия есть, приложение показывает её описание и размер файла, по согласию
скачивает APK с прогрессом, проверяет его и передаёт установку системе.

**Что проверяется перед установкой:** контрольная сумма, номер версии внутри файла
и **подпись** — она должна совпадать с подписью установленного приложения. Файл с другой
подписью отвергается: такой всё равно не встал бы поверх.

**Установку подтверждаете вы.** Тихая установка в Android невозможна: система обязательно
показывает свой диалог. Если установка из этого источника запрещена, приложение откроет
нужный экран настроек.

## Приватность

Приложение не собирает и не передаёт никаких данных о вас и вашей библиотеке. Телеметрии,
аналитики, рекламы и crash-репортинга нет.

Сетевые обращения ограничены двумя контурами, и они **независимы**:

- **Обмен медиа** — запросы к вашему серверу immich в домашней сети. Это и есть работа
  приложения.
- **Проверка обновлений** — обращения только к `api.github.com` и `github.com`.
  **Адрес вашего сервера immich и API-ключ никогда не покидают устройство и не попадают
  ни в один запрос к GitHub** — ни в запросах обновления, ни в логах. `User-Agent` содержит
  только название и версию приложения, без идентификаторов, cookies и модели устройства.

Проверку обновлений можно отключить — переключатель в настройках приложения.

Больше приложение никуда не обращается.

## Чего приложение не делает

- **Не делает автобэкап камеры** — для этого есть официальный клиент immich.
- **Не удаляет ничего автоматически** после переноса.
- **Не разрешает конфликты само**: расхождения между сторонами только показываются,
  решение принимает человек.
- Не публикует ваш сервер в интернет, не настраивает VPN и прокси, не работает
  с несколькими серверами или аккаунтами.
- Не редактирует изображения.
